  - ✅
    ```js
    // ===== main.js =====
    // 입력 받는 준비 두 줄부터 직접 써요
    const fs = require("fs");
    const lines = fs.readFileSync(0, "utf8").split("\n");
    const y = Number(lines[0]);
    if (y % 4 === 0 && y % 100 !== 0 || y % 400 === 0) {
      console.log("1");
    } else {
      console.log("0");
    }
    ```
  - 해설: 윤년 조건 중 4의 배수이면서 100의 배수가 아니어야 하는 부분을 '또는(||)'으로 잘못 묶어서 '그리고(&&)'로 고쳤다.
