## 오늘 배운 것

- **출력:** `console.log("사과", 3, "개")` → 쉼표는 사이에 빈칸이 들어감. 글자를 이어 붙일 땐 백틱 `` `${값}` ``이 제일 편함
- **const와 let:** 바뀌지 않는 값은 `const`, 바뀌는 값만 `let`. `const`에 다시 넣으면 오류
- **몫과 나머지:** 몇 개? → `Math.floor(돈 / 단위)`, 남은 것? → `돈 % 단위`
- **한 바퀴 돌기:** `(지금 + 지난 것) % 한 바퀴` — 시계는 24, 요일은 7
- **자리 숫자 꺼내기:** 일의 자리 `n % 10`, 십의 자리 `Math.floor(n / 10) % 10`
- **입력 받기(준비 두 줄):**
  ```js
  const fs = require("fs");
  const lines = fs.readFileSync(0, "utf8").split("\n");
  ```
  첫째 줄은 `lines[0]`(0부터). 입력은 항상 글자라서 계산하려면 `Number()`
- **한 줄에 여러 값:** `lines[0].split(",")`로 자르고, 조각마다 `trim()`, 숫자면 `.map(Number)`
- **소수 자리:** `toFixed`는 계산이 다 끝난 값 전체에 붙인다 → `(b / (a * a)).toFixed(1)`

## 헷갈렸던 것

- 예제 1, 2는 **코드가 같고 입력만 다르다.** 코드는 한 번만 쓴다
- `const [a, b] = 목록`에서 a, b는 **칸 번호가 아니라 칸에 든 값**. 이름은 아무거나, 순서대로 들어감
- `${ }` 안에는 코드만. 글자(`와`)는 `${ }` 밖에 쓴다
