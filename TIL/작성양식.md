# TIL 작성 양식

> 매일 공부를 마칠 때 10분. 아래 **빈 양식**을 복사해서 `TIL/날짜.md`(예: `TIL/2026-10-21.md`)로 새 파일을 만들어요.

---

## 빈 양식 (복사해서 쓰기)

```markdown
# 2026-10-21

## 오늘 한 것
-

## 배운 것
-

## 헷갈렸던 것
- ❌
- ✅
- 왜:

## 다음에 할 것
-
```

---

## 칸마다 쓰는 법

| 칸 | 무엇을 | 얼마나 |
|---|---|---|
| **오늘 한 것** | 어느 수업, 몇 문제 풀었나 | 1~3줄 |
| **배운 것** | 새로 배운 것 = 한 줄 설명 + 짧은 코드 | 2~3개만 |
| **헷갈렸던 것** | 틀린 코드(❌)와 고친 코드(✅)를 나란히, 이유 한 줄 | 가장 중요! |
| **다음에 할 것** | 내일 시작할 수업·문제 | 1줄 |

---

## 예시

```markdown
# 2026-10-21

## 오늘 한 것
- 4수업(조건문) 문제 5개 풀었다

## 배운 것
- if는 조건이 참일 때만 실행 → if (score >= 60) { console.log("합격"); }
- 비교는 === (= 하나는 값 넣기)

## 헷갈렸던 것
- ❌ if (pw = "1234")
- ✅ if (pw === "1234")
- 왜: = 하나는 비교가 아니라 값을 넣는 거라 항상 참이 됨

## 다음에 할 것
- 4수업 나머지 문제 → 코딩테스트 2단계
```
