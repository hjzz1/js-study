# TIL 작성 양식

일주일에 한 번, 주가 끝날 때 쓴다. 파일 이름은 날짜 범위 + 주차(예: `TIL/11.03~11.09 4주차.md`).

## 빈 양식

```markdown
# 4주차 (11/3 ~ 11/9)

## 한 것
- 11/3
- 11/4

## 배운 것
-

## 헷갈렸던 것
- ❌
- ✅
- 왜:

## 다음 주
-
```

## 쓰는 법

- 한 것: 날짜마다 한 줄. 어느 수업, 몇 문제, 복습 몇 개
- 배운 것: 새로 안 것 2~4개. 한 줄 설명, 필요하면 짧은 코드
- 헷갈렸던 것: 틀린 코드와 고친 코드를 나란히, 이유 한 줄
- 다음 주: 한 줄
